# CampusLife 제품 비전 및 범위

## 1. 비전

CampusLife는 대학 생활 중 여러 앱·채팅방·웹사이트·문서·종이 자료에 흩어지는 정보를 한곳에 수집하고, 맥락을 붙이고, 검색하고, 일정과 학습 활동으로 전환하는 개인 캠퍼스 라이프 허브입니다.

강의 녹음 자동 정리는 첫 번째 핵심 시나리오입니다. 제품을 강의 녹음기나 강의 노트 앱에 한정하지 않습니다. 비강의 정보도 동일한 수집·보관·분류·검색·AI 처리 파이프라인을 이용합니다.

## 2. 관리 범위

### Academic
- 학년도, 학기, 전공/교양 구분
- 과목, 강의자, 강의실, 주간 시간표
- 강의별 녹음, 사진, 슬라이드, transcript
- 강의 요약, 상세 노트, 개념 정리, 참고 자료
- 과제, 프로젝트, 제출물, 마감일
- 시험, 퀴즈, 발표, 평가 일정
- 학습 진도와 복습 상태

### Planner
- 주간/월간 일정, 개인 할 일, 반복 일정
- 마감일, 알림, 우선순위
- 과목·행사·사람·문서와 일정 연결
- AI가 찾아낸 일정 후보는 사용자 확인 후 등록

### Campus
- 학교·학과·학생회 공지, 학사 일정, 행정 안내
- 동아리, 학생회, 스터디, 모임
- 행사, 세미나, 축제, 특강
- 도서관, 시설, 식당, 교통 등 생활 정보
- 참여 기록, 관련 자료, 후속 할 일

### Opportunities
- 장학금, 지원 사업, 공모전, 해커톤, 연구실 모집
- 인턴십, 아르바이트, 채용, 진로 행사
- 자격증, 교육, 비교과 프로그램
- 지원 조건, 마감일, 제출 서류, 진행 상태

### Documents & Personal Inbox
- PDF, 문서, 이미지, 스크린샷, 사진
- 웹 URL, 북마크, 이메일 export
- 음성 메모, 자유 텍스트 메모
- 행정 양식, 신청서, 확인서, 영수증
- 출처, 수집 시각, 원본, 첨부 파일 관리
- 미분류 자료를 받는 통합 Inbox

### Knowledge & Study
- 원본과 파생 문서의 전문 검색
- 과목·학기·태그·날짜·출처 필터
- AI 질문과 근거가 연결된 답변
- 플래시카드, 퀴즈, 간격 반복 복습
- 취약 개념, 주간/학기별 요약, 시험 대비

## 3. 공통 사용자 흐름

1. **Capture:** Android 공유 메뉴, 사진 촬영, 녹음, 파일 가져오기, 웹 링크 또는 수동 입력으로 수집합니다.
2. **Inbox:** 원본 그대로 로컬 Outbox 또는 Windows Inbox에 보관합니다.
3. **Sync:** 장치 연결이 가능하면 Windows 노트북으로 전송합니다. 노트북이 오프라인이면 재시도 대기합니다.
4. **Classify:** 유형과 메타데이터를 감지하고 과목·행사·문서 등의 분류 후보를 만듭니다.
5. **Process:** 사용자가 허용한 경우 OCR, STT, 요약, 일정/할 일 추출 등을 수행합니다.
6. **Review:** 자동 분류와 일정 추출이 맞는지 사용자가 확인합니다.
7. **Organize:** 항목을 도메인 객체 및 관계에 연결합니다.
8. **Retrieve & Act:** 검색, 복습, 마감 관리, 알림, 후속 작업에 활용합니다.

## 4. 비목표 및 경계

초기 버전에서 다음을 자동으로 수행하지 않습니다.

- 학교 계정으로 로그인해 포털/LMS를 무단 크롤링하거나 자동 조작
- 교수자 허락이 확인되지 않은 수업 자동 녹음
- 사용자 확인 없이 AI가 추출한 과제/시험 일정을 실제 일정으로 확정
- 사람의 얼굴·음성 식별이나 생체정보 분석
- 성적 예측, 학생 평가, 출석 조작
- 다중 사용자 공유·소셜 네트워크·학교 공식 LMS 대체
- 노트북이 꺼져 있는 동안 작동하는 상시 클라우드 서버 제공

외부 시스템 연동은 공식 API, 사용자가 제공한 export, 브라우저 공유, 파일 가져오기 등 허용된 방식으로 구현합니다.

## 5. 제품 원칙

- 단일 사용자 우선, 멀티 사용자/공유는 추후 별도 설계
- Windows 노트북을 기본 데이터 허브로 하는 local-first
- 모바일은 오프라인 우선 Capture/Outbox
- 공통 Capture/Item 모델 위에 도메인별 객체 연결
- 원본 불변성, 파생 데이터 버전 관리
- provider-neutral AI pipeline
- 사용자에게 출처와 처리 상태 노출
- 기능 확장보다 데이터 손실 방지와 복구 가능성을 우선

## 강의 자료 수집 범위 확장

강의 Capture는 음성·사진에 한정하지 않습니다. 교수자/조교/학과가 제공하거나 학생이 수집한 다음 자료를 같은 강의 자료 묶음으로 연결할 수 있어야 합니다.

- PDF, PPT/PPTX, DOC/DOCX, HWP/HWPX
- XLSX, CSV, TSV 및 실험/설문 데이터
- 이미지, 스캔 자료, 사진, 다이어그램
- 오디오, 동영상, SRT/VTT 자막
- ZIP 압축 파일, 소스 코드, Jupyter Notebook
- TXT, Markdown, HTML 및 참고 URL

원본은 불변 보존하고 형식별 extractor로 텍스트·표·페이지·슬라이드·시트·시간 정보를 추출합니다. 여러 파일의 내용을 통합 분석하되, AI가 만든 주장과 과제/마감 일정은 원본 위치를 근거로 연결하고 사용자 확인 전 확정하지 않습니다. 상세 설계는 FILE-INGESTION.md를 따릅니다.
